# Сверка калькулятора CRM с Excel

Нужен LibreOffice и файл `Калькулятор_ВольтЛиния.xlsx` (источник истины).

```
cd backend/tests/excel_check
cp ~/…/Калькулятор_ВольтЛиния.xlsx ../calc.xlsx      # путь в fill.py: SRC = '../calc.xlsx'
python3 gen_cases.py 200 23        # случайные замеры → cases.json
python3 fill.py                    # in/caseNNN.xlsx с этими данными
soffice --headless --calc --convert-to xlsx --outdir out in/*.xlsx   # пересчёт формул
PYTHONPATH=../.. python3 compare.py   # построчное сравнение + fixtures.json
```

`fixtures.json` из прогона кладётся в `backend/tests/calc_fixtures.json` — по нему CI проверяет движок без LibreOffice.
Корпус «накладной» в сверку не входит: в Excel (16.11.2026) формула подбора накладного корпуса берёт диапазон
со встраиваемыми корпусами и выбирает корпус больше нужного; в CRM — правильное правило из описания логики.

## Договор (пакет документов ИП)

`app/contract.py` — перенос генератора `make_ip_docs.py` (папка «ВольтЛиния_Клод/Договоры_ИП/_генератор», чат «Договоры от ИП»):
договор, Приложение № 1 — смета работ, Приложение № 2 — спецификация материалов, Приложение № 3 — дизайн-проект (PDF со
штампом), акт выполненных работ. Сверка 16.11.2026 на `пример_объекта.json` в четырёх вариантах (физлицо, ООО, ИП
с материалом заказчика, материалы заказчика): тексты договора и акта, смета xlsx совпали с исходным генератором дословно.
Дополнено под тарифы КП: «Базовый» — цена по факту; «Стандарт»/«Под ключ» — 3/8 бесплатных переносов точек в п. «extra»;
«Под ключ» — второй этап (чистовая установка) с Платежом № 3 и отдельным актом; гарантия 12/36/60 мес. по тарифу.
Цена договора = работы + материалы = цена в КП (строки сметы до копеек). Без эталона пакет проверяет `tests/contract_test.py`.
