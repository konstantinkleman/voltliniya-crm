# ВольтЛиния CRM

Заявки → объекты → бригады и выплаты → расходы → аналитика. Одна система для директора и прорабов.

Логика системы описана в документе «ВольтЛиния CRM — логика системы» (Claude Docs).

## Состав

- `backend/` — FastAPI + SQLAlchemy + PostgreSQL. REST под `/api`, Swagger по `/api/docs` (только после входа).
- `frontend/` — Vite + React + TypeScript. Отдаётся Caddy, который же проксирует `/api` в бэкенд и выпускает TLS.
- `docker-compose.yml` — три сервиса: `db`, `api`, `web`.

## Запуск на сервере

```bash
git clone https://github.com/konstantinkleman/voltliniya-crm /opt/voltliniya-crm
cd /opt/voltliniya-crm
cp .env.example .env   # заполнить пароли, JWT_SECRET, DOMAIN, ADMIN_*
docker compose up -d --build
```

Обновление: `git pull && docker compose up -d --build`.

Бэкап базы: `docker compose exec db pg_dump -U crm crm | gzip > backup-$(date +%F).sql.gz`.

## Правила денег (из документа логики)

- Бригада получает `CREW_SHARE` (0.55) от стоимости работ по смете + доп. работ. Выплата идёт прорабу с пометкой «бригаде».
- Прораб — фиксированная зарплата; распределяется поровну на его объекты месяца сделки.
- Стоимость клиента по каналу = расходы канала за месяц ÷ сделок канала + общий маркетинг ÷ всех сделок.
- Прибыль объекта = договор − материалы по себестоимости − доля бригады − доля зарплаты прораба − стоимость клиента.

Все расчёты — в `backend/app/finance.py`.

## Авито: чаты → CRM, бот-продажник, уведомления

Модуль `backend/app/avito/`. Входящее сообщение из чата Авито попадает в CRM вебхуком: создаётся заявка с источником «Авито» (имя клиента, объявление), переписка пишется в историю заявки, бот на Claude отвечает по скрипту и заполняет поля (площадь, тип объекта, проект, район, время звонка), директору уходит уведомление в Telegram. Если директор пишет в чат сам (из приложения Авито или кнопкой «Ответить» в CRM), бот в этом чате молчит `AVITO_MANUAL_HOLD_HOURS` часов. Раз в неделю бот разбирает переписки, присылает отчёт и черновик новой версии скрипта — включается ссылкой из Telegram или в Настройках.

Подключение (один раз):

1. В Авито: бизнес-профиль, подписка «Расширенный» (в Услугах Messenger API доступен с неё), ключи API в разделе «Интеграции» → `AVITO_CLIENT_ID`, `AVITO_CLIENT_SECRET` в `.env`.
2. Придумать `AVITO_WEBHOOK_SECRET` (длинная случайная строка). Адрес вебхука: `https://crm.voltliniya.ru/api/avito/webhook/<секрет>`.
3. Telegram: токен бота и свой chat_id → `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
4. `ANTHROPIC_API_KEY` для бота. `AVITO_BOT_ENABLED=0` — бот не отвечает, только заносит и уведомляет.
5. `docker compose up -d --build`, затем в CRM: Настройки → Авито → «Подписать» (вебхук) и «Проверить» (Telegram).

Скрипт бота хранится в базе (таблица `sales_scripts`), правится в Настройках без деплоя. Тест без внешних сервисов: `backend/tests/avito.py`.
