# Заявки с сайта voltliniya.ru → CRM

**Установлено 05.11.2026:** `crm-intake.php` лежит в `public_html` рядом с `send.php`; в `send.php` вызов добавлен
после блока Telegram (строки 83–84, в try/catch), перед ответом посетителю.
Форма «Прислать проект на просчёт» (`send-project.php`) — так же, после Telegram: заявка в CRM со ссылками на файлы.

**Директ: поиск и РСЯ.** В шаблоне ссылок кампаний Директа должна быть подстановка `source_type={source_type}`
(search — поиск, context — РСЯ). Без неё CRM отличает РСЯ по словам rsya/рся/context/network в utm_medium/utm_campaign.

Сайт лежит на виртуальном хостинге Timeweb, форма «Заявка на расчёт» отправляется на `/send.php`.

1. Загрузить `crm-intake.php` в ту же папку, что и `send.php`.
2. В `send.php` ПОСЛЕ отправки в Telegram добавить:

```php
require_once __DIR__ . '/crm-intake.php';
vl_send_to_crm($_POST);
```

Источник определяется по UTM-меткам страницы (Директ, SMS, поиск, другое), площадь и ответы формы
попадают в заявку, повтор с того же телефона пишется в историю открытой заявки, бот (поле `website`) отсекается.
Сбой CRM не ломает форму и не мешает Telegram — только запись в лог хостинга.
Токен не нужен: форма шлёт на `/api/intake/site`, который принимает только поля формы (телефон обязателен,
источник — только по меткам, лимит 30 новых заявок в час). Токен `INTAKE_TOKEN` — для Профи и других площадок (`/api/intake/lead`).
