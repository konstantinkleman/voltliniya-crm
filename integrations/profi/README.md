# Профи.ру → CRM: расходы на отклики

У Профи нет API для исполнителей, поэтому расходы собираются из браузера директора (Chrome, вход в Профи и в CRM выполнен).

Каждый день запланированная задача Claude:
1. открывает https://profi.ru/backoffice/bill.php и выполняет на странице `collect-spend.js` —
   он открывает «Историю транзакций», подгружает все строки текущего месяца (а 1–5 числа и прошлого)
   и считает **деньги, потраченные на канал** = списания в ₽ (отклики, Профи-премиум, абонементы) − возвраты в ₽.
   Бонусы и пополнения баланса не учитываются;
2. открывает https://crm.voltliniya.ru и от сессии директора отправляет каждую сумму в
   `POST /api/expenses/upsert` с `category: "profi"`, `external_ref: "profi:YYYY-MM"`.

В «Расходах» CRM — одна строка «профи.ру» на месяц с пометкой «авто»; повторная отправка обновляет сумму.

Если сессия CRM в Chrome истекла (раз в 30 дней), задача сообщит об этом — нужно войти в CRM заново.
